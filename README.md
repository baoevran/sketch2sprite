# sketch2sprite

Dieses Projekt erzeugt Pixel-Art-Sprites aus Skizzen. Es vergleicht dafür zwei Modelle,
ein bedingtes GAN (cGAN, pix2pix-Ansatz) und ein Diffusionsmodell, jeweils in 32x32
(mit Hochskalierung) und in 512x512.

Projekt im Modul "Advances in Intelligent Systems".
